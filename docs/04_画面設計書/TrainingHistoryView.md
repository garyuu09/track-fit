# トレーニング履歴画面 (TrainingHistoryView)

## 画面概要

過去のトレーニング記録を一覧表示する画面。日付別・種目別で履歴を確認できる。

## 画面遷移

| 入口 | 出口 |
|------|------|
| タブバー（履歴） | 種目詳細画面, カレンダー履歴画面 |

## 表示要素

- 検索バー
- リスト/カレンダー表示切替
- トレーニング記録一覧

## イベント定義

| イベント | トリガー | 処理 |
|---------|---------|------|
| 記録タップ | リストアイテム | 種目詳細画面へ遷移 |
| カレンダー表示 | カレンダーアイコン | カレンダー履歴画面へ遷移 |
| 検索 | 検索バー入力 | 記録のフィルタリング |
| 削除 | スワイプ | 記録の削除 |
