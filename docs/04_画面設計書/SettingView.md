# 設定画面 (SettingView)

## 画面概要

アプリの各種設定を行う画面。テーマ、カレンダー連携、種目管理などを設定できる。

## 画面遷移

| 入口 | 出口 |
|------|------|
| タブバー（設定） | 種目管理画面, カレンダー連携画面, プライバシーポリシー |

## 表示要素

### 外部連携セクション
- カレンダー連携機能トグル
- Googleカレンダー連携状態
- イベントの色設定

### App Settingsセクション
- テーマカラー（ライト/ダーク/システム）
- 種目管理へのナビゲーション

### Aboutセクション
- プライバシーポリシー
- バージョン情報

## Enum

### DisplayMode

| 値 | 説明 |
|-----|------|
| `light` | ライトモード |
| `dark` | ダークモード |
| `system` | システム設定に従う |

### CalendarEventColor

11色から選択可能（みかん、トマト、フラミンゴ等）

## イベント定義

| イベント | トリガー | 処理 |
|---------|---------|------|
| カレンダー連携 | 「連携する」ボタン | Google Sign-Inフロー開始 |
| 連携解除 | 「連携を解除」ボタン | トークン削除, 状態リセット |
| テーマ変更 | Picker選択 | AppStorageに保存 |
| 種目管理 | ボタンタップ | 種目管理画面へ遷移 |

## API連携

| API | タイミング | 説明 |
|-----|---------|------|
| Google Sign-In | 連携ボタン押下 | OAuth認証フロー |
