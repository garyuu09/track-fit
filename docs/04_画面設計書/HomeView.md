# ホーム画面 (HomeView)

## 画面概要

ユーザーのトレーニング統計情報とアクティビティヒートマップを表示するダッシュボード画面。

## 画面遷移

| 入口 | 出口 |
|------|------|
| タブバー（ホーム） | - |

## 表示要素

- トレーニング統計（総セット数、ボリュームなど）
- アクティビティヒートマップ（日別トレーニング実施状況）

## ViewModel

`HomeViewModel`

### 主要プロパティ

| プロパティ | 型 | 説明 |
|----------|-----|------|
| `totalSets` | Int | 統計: 総セット数 |
| `totalVolume` | Double | 統計: 総ボリューム |
| `activityData` | [Date: Int] | ヒートマップ用データ |

## イベント定義

| イベント | トリガー | 処理 |
|---------|---------|------|
| 画面表示 | `onAppear` | データ取得・統計更新 |
