# 種目管理画面 (ExerciseManagementView)

## 画面概要

トレーニング種目の追加・編集・削除を行う管理画面。カテゴリ別に種目を管理できる。

## 画面遷移

| 入口 | 出口 |
|------|------|
| 設定画面 | 種目選択画面（カテゴリ選択時） |

## 表示要素

- カテゴリ一覧
- 各カテゴリの種目一覧
- 種目追加フォーム

## ViewModel

`ExerciseViewModel`

## イベント定義

| イベント | トリガー | 処理 |
|---------|---------|------|
| 種目追加 | 追加ボタン | SwiftDataに保存 |
| 種目編集 | リストアイテムタップ | 編集フォーム表示 |
| 種目削除 | スワイプ削除 | SwiftDataから削除 |
| カテゴリ選択 | カテゴリタップ | 種目選択画面へ遷移 |
