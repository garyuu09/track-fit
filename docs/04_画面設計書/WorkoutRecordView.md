# トレーニング記録画面 (WorkoutRecordView)

## 画面概要

新規トレーニングを記録するためのメイン画面。種目ごとに重量・回数・セット数を入力し、保存する。

## 画面遷移

| 入口 | 出口 |
|------|------|
| タブバー（トレーニング記録） | 種目選択画面, ワークアウト編集画面 |

## 表示要素

- 種目フィルター（全て/お気に入り）
- 種目一覧
- 記録追加ボタン

## ViewModel

`WorkoutViewModel`

### Enum: FilterType

| 値 | 説明 |
|-----|------|
| `all` | 全ての種目を表示 |
| `favorites` | お気に入りのみ表示 |

## イベント定義

| イベント | トリガー | 処理 |
|---------|---------|------|
| 種目選択 | 種目カードタップ | 種目選択画面へ遷移 |
| 記録保存 | 保存ボタン | SwiftDataに保存, カレンダー連携 |
| フィルター切替 | セグメントコントロール | 表示種目のフィルタリング |

## API連携

| API | タイミング | 説明 |
|-----|---------|------|
| Google Calendar API | 保存時 | カレンダー連携有効時にイベント作成/更新 |
