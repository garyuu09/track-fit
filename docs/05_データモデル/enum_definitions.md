# 区分値・定数定義書

TrackFitアプリで使用する区分値（Enum）を定義します。

---

## ENUM01: TabSelection

### 区分値概要

| 項目 | 値 |
|------|-----|
| 目的 | タブバーの選択状態を管理 |
| 物理名 | `TabSelection` |
| 定義場所 | `ContentView.swift` |

### 区分値定義

| 論理名 | 物理名 | コメント |
|--------|--------|----------|
| ホーム | `home` | ホームタブ |
| トレーニング記録 | `workout` | トレーニング記録タブ |
| 履歴 | `history` | トレーニング履歴タブ |
| 設定 | `setting` | 設定タブ |

---

## ENUM02: DisplayMode

### 区分値概要

| 項目 | 値 |
|------|-----|
| 目的 | アプリの表示テーマを切り替える |
| 物理名 | `DisplayMode` |
| 型 | `String` (RawRepresentable) |
| 定義場所 | `SettingView.swift` |

### 区分値定義

| 論理名 | 物理名 | 値 | コメント |
|--------|--------|-----|----------|
| ライト | `light` | "light" | 常にライトモード |
| ダーク | `dark` | "dark" | 常にダークモード |
| システム | `system` | "system" | OS設定に従う |
